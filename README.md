# 🛡️ Cybersecurity Toolkit Repository

Welcome to the **Cybersecurity Toolkit Repository** — a curated collection of tools, cheat sheets, mindmaps, and resources for learning, practicing, and mastering cybersecurity. Whether you're a beginner or a seasoned professional, this repository provides essential resources across a broad spectrum of cybersecurity domains.

---

## 📂 Repository Structure

This repository is organized into multiple folders, each representing a tool, concept, or framework. Below is a categorized list of the contents:

### 🔍 Web Application Security
- **Burp Suite** – Proxy-based web security testing
- **OWASP** – Security best practices and top vulnerabilities
- **XSS Tools** – Cross-Site Scripting exploitation resources
- **SSRF Tools** – Server-Side Request Forgery tools
- **Sqlmap** – SQL Injection automation
- **FFUF / Gobuster / Feroxbuster** – Directory brute-forcing
- **WFUZZ / HTTPX / Wpscan** – Web fuzzing and scanning

### 🧠 Offensive Security
- **Metasploit / Empire / CrackMapExec / Mimikatz** – Exploitation frameworks and post-exploitation tools
- **Hydra / Medusa / John / Hashcat** – Password cracking tools
- **Nmap / Tcpdump / Tshark** – Network scanning and packet analysis
- **Impacket / SMB Enumeration / Windows Privileges** – Lateral movement and privilege escalation
- **Aircrack / Wireless Pentest Tools** – Wireless network attacks

### 🕵️‍♂️ OSINT & Reconnaissance
- **Shodan / Censys** – Internet-wide scanners
- **Google Dorks / Github Dorks / Search Engine for Pentesters** – Advanced search techniques
- **OSINT / Enumeration / Subdomain Enumeration** – Recon resources and automation

### 💼 Red Team & Penetration Testing
- **HTB / TryHackMe / Vulnhub** – Labs and practice platforms
- **Mitre ATT&CK** – Threat tactics and techniques matrix
- **Active Directory Pentesting** – AD attack vectors and mindmaps
- **Red Team Dorks / Tools / Zero-Day CVEs** – Offensive intelligence

### 🔐 Blue Team & Forensics
- **Forensics** – Digital investigation tools
- **Cloud Security Framework / DevOps / Container Security** – Cloud-native security practices
- **Cyber Security Attack / Cybersec Technologies / Security Automation / Security 360** – Enterprise security modules

### 🔧 Utilities & Miscellaneous
- **Privacy Tools / Privacy Search Engines / Email Accounts** – Anonymity and OPSEC
- **Firefox Pentest Add-ons** – Browser extensions for testing
- **HTTP Status Codes / ICMP / ISO Control / IDAPro** – Reference material
- **Google Search Operators** – Advanced query techniques
- **Gtfobin** – GTFOBins for privilege escalation
- **NIST / Ransomware / Other** – Compliance and incident response
